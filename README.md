# Fortius Rewards

The member rewards app for CrossFit Fortius in San Diego, served at https://rewards.crossfitfortius.com from GitHub Pages.

Until the program launches on December 1, 2026, the site shows a placeholder. At launch it holds the app and one data file, rebuilt each week. The data file carries only hashed emails and first names with last initials.

Since November 19, 2026, board/ holds a pre-launch copy of the Fortius Grit Club board for the TV at the gym. It shows first names with last initials and no point values. At launch the full board replaces it.
